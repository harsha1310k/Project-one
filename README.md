# Expense Tracker

A simple command-line Python application to track daily expenses. Built to practice working with file handling, structured data, and date/time operations in Python.

## Features
- Add new expense entries with amount, category, and date
- Store expense data persistently using JSON
- View and review past expenses
- Automatically timestamp entries using the `datetime` module

## Technologies Used
- Python 3
- `json` — for storing and retrieving expense data
- `os` — for file handling
- `datetime` — for tracking when expenses were added

## How to Run
```bash
python expense_tracker.py
```
